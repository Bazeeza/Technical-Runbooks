## Why an archive

A runbook in this repository is written in original words, follows [TEMPLATE.md](../TEMPLATE.md) and cites the official documentation it was checked against. These notes do none of that, so they are separated from the runbooks instead of being presented as original content.

A topic from this archive can return as a real runbook: rewritten from scratch, sourced, and following the template.
